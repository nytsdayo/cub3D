# cub3D 拡張機能ガイド

## クイックスタート

### ビルド
```bash
make
```

### 実行
```bash
./cub3D assets/maps/Success/test_door.cub
```

---

## 操作方法

### 基本操作
| キー | 動作 |
|------|------|
| W | 前進 |
| S | 後退 |
| A | 左へ移動 |
| D | 右へ移動 |
| ← → | 視点回転 |
| マウス移動 | 視点回転 |
| ESC | 終了 |

### 追加機能
| キー | 動作 |
|------|------|
| **E** | **ドアの開閉** |

---

## 新機能

### 1. ミニマップ 🗺️

**場所**: 画面左上

**表示内容**:
- **白**: 壁
- **黒**: 床
- **茶色**: 閉じたドア
- **緑**: 開いたドア
- **赤**: プレイヤー（あなた）

### 2. ドア 🚪

**マップでの記述**: `D`

**動作**:
- Eキーで開閉
- 閉じたドア: 通行不可
- 開いたドア: 通行可能
- **安全機能**: ドア内では閉じられません

```
1111111111111

1000000000001

```

## トラブルシューティング

### ドアが開かない
- プレイヤーがドアを向いているか確認
- ドアから2マス以内にいるか確認
- Eキーを押しているか確認

### ミニマップが見えない
- 画面左上（10px オフセット）を確認
- ウィンドウサイズが十分か確認

### メモリリーク確認
```bash
valgrind --leak-check=full ./cub3D <map_file>
```
