# Door Feature Test Cases

このディレクトリには、ドア機能に関連するテストケースが含まれています。

## テストケース一覧

### 1. door_on_edge.cub ✅ FAILS
**テスト内容**: マップの端（外周）にドアが配置されている
**実際の動作**: ❌ Error: Map is not enclosed by walls
**理由**: ドアは壁の一部として扱われるが、外周の壁がドアになると境界が開放される可能性があるため禁止

### 2. door_no_player.cub ✅ FAILS
**テスト内容**: プレイヤーがいないマップにドアのみ配置
**実際の動作**: ❌ Error: No player start position found
**理由**: ドアの有無に関わらず、プレイヤーは必須要素

### 3. door_space_around.cub ✅ FAILS
**テスト内容**: ドアの周囲にスペース文字が配置
**実際の動作**: ❌ Error: Space character touches void area
**理由**: スペースは外部として扱われるため、境界検証でエラーとなる

### 4. door_isolated.cub ⚠️ PASSES (仕様として許可)
**テスト内容**: 周囲に壁がない孤立したドア（床の中に単独配置）
**実際の動作**: ✅ 正常に動作（ドアは壁として機能）
**理由**: 現在の実装ではドアは壁と同等に扱われるため、配置位置に制限なし

### 5. door_multiple_adjacent.cub ⚠️ PASSES (仕様として許可)
**テスト内容**: 複数のドアが隣接して配置（DDD）
**実際の動作**: ✅ 正常に動作（各ドアが独立して動作）
**理由**: 各ドアは独立して管理され、隣接配置も問題なく動作

### 6. door_corner.cub ⚠️ PASSES (仕様として許可)
**テスト内容**: マップの角（内側）にドアが配置
**実際の動作**: ✅ 正常に動作
**理由**: 角の位置であっても、ドアは壁として機能するため問題なし

### 7. door_only_map.cub ⚠️ PASSES (仕様として許可)
**テスト内容**: 通路がほぼドアのみで構成されるマップ
**実際の動作**: ✅ 正常に動作
**理由**: ドアは壁の一種として扱われ、開閉可能な壁が多数あるだけで問題なし

## テスト結果サマリー

### 失敗するテスト（期待通り）: 3個
1. door_on_edge.cub - 外周にドア配置
2. door_no_player.cub - プレイヤー不在
3. door_space_around.cub - ドア周辺にスペース

### 成功するテスト（仕様として許可）: 4個
4. door_isolated.cub - 孤立ドア配置
5. door_multiple_adjacent.cub - 隣接ドア配置
6. door_corner.cub - 角にドア配置
7. door_only_map.cub - ドア主体マップ

## 注意事項

- 現在の実装では、ドアは「開閉可能な壁」として扱われます
- ドアの配置に特別な制限はなく、壁が配置できる場所ならどこでも配置可能です
- 外周の壁チェックは従来通り機能し、ドアが外周にある場合はエラーとなります
- 将来的に「ドアは両側に壁が必要」などの制約を追加する場合は、追加のバリデーションが必要です
